# JBK Game Engine
JBK-Game-Engine is a simple game engine with it's own:
1. Syntax: New functions
2. Runner: Runs the .jbk
3. Logo: A custom shield and square logo
4. Simplicity: Simple code, while still being fun
5. Modes: Normal graphical "Window" mode, and Command Prmpt mode!
And more!

Made by @KernFern-Studios, KernFern Studios is an independent Game & Software Development Studio, they make **file types**, and simple **software** sometimes.

Here is a simple, 5 line game for you!:


GameWindow(Title: Tiny Bounce)

Make var name: (Player)

Player Shape: Circle

Player Position: (200, 200)
